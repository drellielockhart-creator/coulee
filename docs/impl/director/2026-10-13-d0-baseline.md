# D0 baseline: the land itself, 2026-10-13

All three 365-day runs use `land_itself`, budget 0 and `foresight=tiltable`. No nudges, RNG draws, LOD pins or changes to actor agency occur. CLI observes the scenario-designated PC while everyone continues using their ordinary AI. These are passive fixture baselines, not commanded newcomer playtests. Each run is 8,760 hours, April 1, 1855 through March 30, 1856 (the endpoint is March 31 because 1856 is a leap year).

The pure sim produces almost no large tension arcs for these sheltered PCs. The classifier leaves RELAX after seven days and stays in BUILD: it never reaches its 700-point peak threshold. Large numbers of partial social matches coexist with long gaps in salient events the PC can perceive. This is the distinction D1 must address: activity somewhere in town is not necessarily a story reaching the player.

## Knowledge and calibration

See [the measurement contract](D0-MEASUREMENT.md) for term normalization, EMA initialization, knowledge filtering, gun windows, thread closure and retention. Tension and its averages are 0–1000. Dead-air hours contain no fair-perceived event reaching the Chronicle Journal salience threshold; dead-air days are complete 24-hour blocks with no such event. The metric includes Chronicle notoriety, PC involvement and fatigue, but excludes repeat suppression. It does not equate all quiet hours with a bad play experience.

## Which patterns dominate

Cells are opened / resolved / abandoned; unmatched partials count as opened. Pending threads and threads still inside their inactivity/window retention account for the difference. These totals are **not incident counts**. In particular, help can open a possible betrayal or friendship before either transformation occurs. “Expired unseen” records visibility at expiry. Guns use conservative, pattern-local consequence matching and the declared fire window; a related event in a different pattern is not automatically counted as payoff. Seen and fired are independent: the world can settle something off-screen. Unseen expiration is permitted by the design and is not, alone, a failure. The actionable gap is how little of the material reaches the PC before it resolves or expires.

## Where the story is flat

- There is little rise-and-release in the observed tension curves. The classifier has no PEAK/FADE cycles to measure after its initial rest. D1 should first test whether meaningful existing threats can reach the PC; simply lowering the peak threshold would change the label, not the underlying experience.
- The world generates many social fragments, but the watched PCs have whole quiet days and multi-day gaps between salient perceived events. Discovery and believable rumor delivery are more directly supported by this baseline than adding arbitrary danger.
- Friendship/betrayal candidate churn inflates thread-open counts. Judge D1 by visible progress and payoffs, not by a larger registry. Keep the gun-window and visibility definitions fixed when comparing runs.
- Quiet living in town is a valid outcome. These passive fixture runs must be supplemented with commanded headless play before deciding that every long quiet interval needs intervention.

## Cost and validation

The final Iron Ford year costs **2.253 ms/game-hour** in the scheduled Director system. The **<0.5 ms/h target is not met**. The initial full-three-day query measured 2.476 ms/h; safe maximum-based horizon pruning reduces work while preserving tension. A CPU profile of the initial implementation attributed about 95% of Director samples to tension measurement, overwhelmingly the P8 projection. No hourly stale cache or shortcut around meal/storage rules was introduced to hide that cost. The saved Director slices occupy 3.29 MB / 0.94 MB / 1.09 MB as ordinary JSON (Iron Ford / Town 7 / Town 19); packed total saves are 7.28 MB / 4.57 MB / 4.98 MB. Candidate churn and retained interest Explains are also worth reducing before a phone-facing D1 pass. Measurements were taken on the shared, loaded machine. Chronicle’s projection callbacks are charged to Chronicle by the existing schedule profiler.

## Reproduction and artifacts

```sh
just run run --scenario iron_ford --seed 42 --years 1 --profile --no-events --save --out runs/director-d0-baseline-iron-ford-42
just run run --scenario gen:town --seed 7 --years 1 --profile --no-events --save --out runs/director-d0-baseline-town-7
just run run --scenario gen:town --seed 19 --years 1 --profile --no-events --save --out runs/director-d0-baseline-town-19
just run director report --run runs/director-d0-baseline-iron-ford-42
VITEST_MAX_WORKERS=2 just check
```

Each run directory contains manifest (monthly terms/EMAs/pacing, knowledge-filtered dead air, thread/gun totals, top ten, settings and profiling), final-hash, save, daily stats and Chronicle. Generated towns use generator v2 with world seed equal to simulation seed. Scratch proof runners and their JSON comparisons are under `runs/scratch/d0-{proof,production-proof,production-after}*`; `d0-main/` is the archived original core. All run artifacts remain gitignored.
