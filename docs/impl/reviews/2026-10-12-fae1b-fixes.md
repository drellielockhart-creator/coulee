## Implementation notes

- All social edits are in `social/objects.ts`. The sole provisions change is the meal kernel calling the item-access API before fractional consumption; no credit/relief/economy behavior is edited.
- Forfeit records are optional fae-owned state with the six existing canon categories, counterparty, and expiry. Explicit `faeActors` identifies Fair Folk actors without treating mortal ancestry as fae identity. Existing instrument charms used by mortal keepers retain their policy.
- Restitution reports are learned through tracing, study, or an item conversation; preflight and payment use the same actor-specific amount. Hidden bookkeeping remains in draw cases.
- Item access metadata is stored on item stacks, not the shared fae slice, so planner copies remain isolated.
- No golden update has been made.
